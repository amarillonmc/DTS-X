# 原生移植与验收记录

分支：`XX`。基线：`dts/Unstable`，提交 `ba8f607a57d5352327113f41b32676d16fe7c3ba`。用户要求整个项目改为原生 Node.js，并保留全部原玩法、机制和资源。

## 实现范围

779 个模块均有静态 JavaScript 实现，保留默认启用的 770 个模块及原关闭项。48 个模块直接移植，582 个技能与其余 149 个模块由开发期转换工具生成普通 async JavaScript；生产通过静态 import 调用。模块分派保留 FIFO 依赖顺序、覆盖链、直接调用、变量引用、请求隔离和真实调用帧。没有 PHP 执行器、WASM、动态 eval 或运行时 AST 解释器。

已接入原生账号注册、登录、资料、卡片、成就、用户设置、管理页、消息及附件、房间、聊天、排行榜、调度、维护和跨服接口。数据库使用 mysql2，保留原 SQL、数字字符串、二进制和 MyISAM/MEMORY 语义；OS 文件锁失效即失败。HTTP 保留原 URL、表单、压缩协议、Cookie、原经典界面和可切换现代界面。

882 个模板已静态迁移，包含模块模板绑定、两个原主题、引用、全局和输出缓冲。帮助、合成、NPC 等派生页面缓存以私有数据或最终 HTML 保存，不执行缓存代码。原资源路径与 3,578 个来源文件保持不变。

Git 属性对 `engine/` 禁用换行转换，原生静态构建固定 LF，以免另一台机器检出后破坏来源或模板哈希。旧索引曾规范化来源文件换行，现已按未改动的工作区原字节重新纳入；12 个被旧忽略规则遮蔽的原文件也已补入，未修改来源 `.gitignore` 或来源清单。Git 中的换行差异不是游戏逻辑改造。

录像从真实成功指令记录，沿原条件筛选、归档、拆分、解压，继续由原浏览器脚本播放。响应字典采用显式无压缩字典标识，浏览器仍按原协议解码；BMP 及其他二进制资源保留字节。

## 2026-10-23 原生请求性能回归

同机回环 HTTP 复现了操作延迟。CPU 采样显示公共数组复制是主要热点；每个请求的头像列表还会枚举最多上千个编号，对缺失图片逐个发起文件调用。Node 的 JavaScript 模块本已常驻，这些开销发生在请求初始化和规则执行期间。

本次优化数组复制的标量与数据字段路径，保留引用访问器、字节数组、键顺序和删除桶；生成规则共用无请求状态的值辅助函数，模块导入访问器仅在本请求内复用。头像按请求读取一次目录名称，缺失的普通文件名直接排除，已有文件仍检查真实路径和文件类型；无法列目录时保留逐文件查询，新增图片在下次请求可见。玩家、房间、随机数、输出、数据库连接和锁仍按请求隔离，未改写原资源或钩子顺序。

## 2026-10-23 继续降低请求延迟

本轮继续针对 50ms 常规操作、120ms 最大值的目标优化原生路径。应用常驻模块调用计划、技能元数据与模板绑定；启动时预载静态模板函数，运行时复用已载入函数。请求仍独立执行原初始化与全部钩子，不共用玩家、随机数、输出、数据库连接或锁。复用异步上下文载体时，以独立标识隔离会话栈和输出捕获，不让载体持有整个会话。

开发编译器对纯字面量配置建立不可变模板，按访问惰性复制子数组；卡片表中的六次随机计算仍在原位置和顺序执行。可证明为静态访问的局部作用域只绑定所需导入字段；动态变量和作用域逃逸保留完整导入。只对已审计、指纹匹配的六个配方返回函数移交独占临时值，引用槽继续复制。公共数组辅助函数保留引用、数字键、删除桶和随机语义。生成 JS 在原文件上应用转换并更新对应产物哈希，没有重新覆盖既有机制修复。

应用的玩家表列定义与原始头像目录缓存只保存静态元数据，各请求仍获得独立头像数据。头像扩展钩子保留原调用顺序；图片实际读取、符号链接及通用文件查询保留路径检查。直接更新头像或修改玩家表结构后，须重启或重新应用模块清单。文件服务仅复用同一次路径校验取得的元数据；录像仍在真实 OS 锁下写入，字典冲突和写入失败继续报错。注册题库只复用相同文件字节的解析结果，文件本身仍重新读取。

- OS 锁等待失败时拒绝写入；备份先成功生成快照再轮换。自动维护保留原操作与日期判断，修复原旧进度恢复文件错误，进度保存为原子 JSON。
- 远端账号和录像授权名单来自私有 JSON，默认为空；不启用源码样例密钥。开发编解码页只允许可信回环地址。HTTP 不公开源文件、SQL、配置、存档或凭据。
- 两个 2015 年历史用户升级工具保留原来源并提供管理员只读审计，不自动重复发奖或改表；原补卡工具还含缺失参数错误。
- 原 skill960/skill961 调用不存在的裸全局 `skill_lost`，开发编解码页的旧成就 helper 也引用不存在函数。这些来源缺陷明确保留并由审计列出；未擅自补出另一套机制。

随机数组另以实际随机合成、除错任务、唱歌配置和随机 NPC 技能生成做差分，保留删除桶、筛选后重建、数字键插入顺序和后续随机消耗。

日期输出检查了静态规则/模板中的 19 个实际调用点、8 种格式及 96 次 PHP 输出，并以技能 539 的 26 场复活倍增/到期场景对照完整日志。原技能的 `hh:mm:ss` 格式原样保留，不将来源中重复的格式符擅自修成另一种显示。

当前数值边界也须明确：JSON 数值超过 JavaScript 安全精度会拒绝，单次 range 限制为一百万项；没有给每个 Number 附加通用 PHP int/float 类型标签。原教程中唯一的 is_int/is_float 判断输入来自分割后的字符串，已检查该真实调用点，但不宣称实现完整 PHP 类型系统。

全部技能叠加、随机种子、玩家竞态与所有结局路径没有被穷举。Windows / Node.js 26.5.0 / PHP 7.4.33 对照及真实 Edge 是本轮实际环境；没有 Docker 执行环境，因此不宣称已验证 Linux/Compose 部署。生产前仍应在目标平台演练备份恢复和容量。

旧服切换应在局间并先完整备份。不要将仍未归档的旧压缩响应和新无压缩字典混在一个当前录像目录中；已归档录像带独立字典引用。新原生默认状态目录独立于旧 `var/game`，旧库也不会被安装器认领。部署细节见 [DEPLOYMENT.md](DEPLOYMENT.md)。
