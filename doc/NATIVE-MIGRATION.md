# 原生移植与验收记录

分支：`XX`。基线：`dts/Unstable`，提交 `ba8f607a57d5352327113f41b32676d16fe7c3ba`。用户要求整个项目改为原生 Node.js，并保留全部原玩法、机制和资源。

## 实现范围

779 个模块均有静态 JavaScript 实现，保留默认启用的 770 个模块及原关闭项。48 个模块直接移植，582 个技能与其余 149 个模块由开发期转换工具生成普通 async JavaScript；生产通过静态 import 调用。模块分派保留 FIFO 依赖顺序、覆盖链、直接调用、变量引用、请求隔离和真实调用帧。没有 PHP 执行器、WASM、动态 eval 或运行时 AST 解释器。

已接入原生账号注册、登录、资料、卡片、成就、用户设置、管理页、消息及附件、房间、聊天、排行榜、调度、维护和跨服接口。数据库使用 mysql2，保留原 SQL、数字字符串、二进制和 MyISAM/MEMORY 语义；OS 文件锁失效即失败。HTTP 保留原 URL、表单、压缩协议、Cookie、原经典界面和可切换现代界面。

882 个模板已静态迁移，包含模块模板绑定、两个原主题、引用、全局和输出缓冲。帮助、合成、NPC 等派生页面缓存以私有数据或最终 HTML 保存，不执行缓存代码。原资源路径与 3,578 个来源文件保持不变。

Git 属性对 `engine/` 禁用换行转换，原生静态构建固定 LF，以免另一台机器检出后破坏来源或模板哈希。旧索引曾规范化来源文件换行，现已按未改动的工作区原字节重新纳入；12 个被旧忽略规则遮蔽的原文件也已补入，未修改来源 `.gitignore` 或来源清单。Git 中的换行差异不是游戏逻辑改造。

录像从真实成功指令记录，沿原条件筛选、归档、拆分、解压，继续由原浏览器脚本播放。响应字典采用显式无压缩字典标识，浏览器仍按原协议解码；BMP 及其他二进制资源保留字节。

## 明确差异与保留边界

2026-10-23 教学疗伤和现代移动下拉框回归：`command.php`（含原生 `act.php` 别名）的 `CURSCRIPT` 恢复为原版的 `game`，防止异步人物面板省略伤口点击事件。现代点击录像沿占位节点计算原 DOM 路径，避免重挂载控件导致原生下拉框在鼠标松开时关闭；原素材和模板未改动。

两个故障均先由回归复现。`native-tutorial-http` 使用独立 MySQL、真实教程房间、默认 770 模块及 Edge，覆盖两种原主题 × 经典/现代界面的四种组合：面包推进到包扎步骤、体力恰好 50 时拒绝治疗、体力充足时点击治愈、技能移除、下一步骤与体力跨请求持久化。教程原本排除录像，测试保留该排除；普通局录像仍由 `native-full-gameplay` 验证。`native-request-host` 检查两种主题四处伤口的可点击条件及战斗/非游戏页面禁用条件。现代合成浏览器回归验证下拉框真实按下/松开/选择、所有控件原路径、嵌套搬移、OPTION 暂停与重复过滤。该范围不代表整个教程或所有技能组合均已穷举。

本次完整套件实际运行两轮：`npm test -- --test-concurrency=4` 为 **1238/1240 通过、2 失败、0 跳过**（403.9 秒）；失败为双账号 HTTP 测试的地图请求 500，以及 882 模板 PHP 对照进程超过 45 秒。两项单独复测分别在 52.2 秒、23.6 秒通过。第二轮 `npm test -- --test-concurrency=2` 为 **1239/1240 通过、1 失败、0 跳过**（392.6 秒），所有原生测试通过，唯一失败为未修改的旧 `runtime/prepare.mjs` 在生命周期临时目录原子重命名 `server.config.php` 时遇到 Windows `EPERM`，该项单独复测通过。未通过删锁、改存档、放宽生产错误处理或关闭防护来绕过失败；文件占用来源和首轮地图请求错误的确切原因尚未确认，不能把独立复测写成完整套件全绿。日志保留于忽略目录 `var/tests/interaction-full-suite.log`、`interaction-full-suite-2.log`、`interaction-http-recheck.log`。
